# AutoMaster CRM / AutoShop — схема бази даних

Цей репозиторій містить SQL-схему CRM для автосервісу на Supabase (PostgreSQL). Це **не** вихідний код Supabase CLI і не готовий застосунок із вебінтерфейсом чи сервером.

## Що є в репозиторії

- [`supabase/full_schema.sql`](supabase/full_schema.sql) — повна схема та логіка БД; у заголовку файла зазначено запуск через Supabase SQL Editor.
- [`supabase/migrations/`](supabase/migrations/) — збережена SQL-міграція віддаленої схеми.
- [`LICENSE`](LICENSE) — ліцензія цього репозиторію.

Стан репозиторію відображає знімок коду станом на грудень 2025 року. Поточний стан розгортання тут не описаний.

## Перед застосуванням SQL

Перегляньте обидва SQL-файли й перевірте потрібний шлях розгортання на окремому тестовому проєкті Supabase. Не запускайте повну схему та міграцію послідовно без перевірки їхнього перетину. Для наявної бази спершу зробіть резервну копію й перевірте різницю схеми.

У цьому репозиторії поки немає перевіреної процедури міграції для чинної інсталяції, команд тестування чи інструкцій розгортання застосунку.
